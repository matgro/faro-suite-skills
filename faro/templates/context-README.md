# Índice del proyecto

Este índice enumera los recursos útiles para agentes y personas que trabajan en el proyecto. Cada viñeta debe indicar **ubicación**, **descripción** y **propósito**. Reemplaza los marcadores sólo con hechos confirmados.

## Repositorios de código

- **Ubicación:** Pendiente de confirmar. **Descripción:** Repositorio principal de código. **Propósito:** Implementación y pruebas del producto.

## Documentación

- **Ubicación:** `AGENTS.md`. **Descripción:** Instrucciones y contrato FARO del proyecto. **Propósito:** Guiar el trabajo de agentes.
- **Ubicación:** `context/`. **Descripción:** Estado, índice, workflow y arquitectura del proyecto. **Propósito:** Mantener contexto técnico y continuidad de trabajo verificables.

## Fuentes de entrada

- **Ubicación:** Pendiente de confirmar. **Descripción:** Fuentes de datos, requisitos o materiales de referencia. **Propósito:** Sustentar el alcance y las decisiones.

> Si no existen fuentes de entrada, reemplaza la viñeta pendiente por una declaración explícita: «No hay fuentes de entrada registradas». No elimines la sección.
