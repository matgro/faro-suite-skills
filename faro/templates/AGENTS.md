## FARO — instancia gestionada

- Contrato instalado: FARO `2.0.0`.
- Manifiesto de instancia: `context/faro-workspace.json`.
- Estado e identidad: `context/stats.json`.
- Índice de fuentes: `context/README.md`.
- Configuración específica del proyecto: `context/requirements/project-profile.md`.
- Localizador de expedientes: `context/requirements/requirements-catalog.md`.
- Localizador funcional: `context/requirements/functional-documents-catalog.md`.
- Documentación funcional vigente: `context/requirements/functional/`.
- Expedientes RM/BUG/TEC de ruta estable: `context/requirements/work-items/`.
- Continuidad activa: `context/workflow.json`, si existe.

Las reglas de inicialización, diagnóstico, ruteo, Jira, autorización y entrega
pertenecen a las skills centrales FARO. Este bloque identifica la instancia local;
no redefine esas reglas. Preservar siempre las instrucciones externas a este bloque.
